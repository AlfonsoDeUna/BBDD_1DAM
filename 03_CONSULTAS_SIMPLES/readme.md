# 03 · Consultas simples — SELECT básicas

Presentación interactiva para la primera clase de consultas SQL en **1.º DAM · Bases de Datos**, utilizando una tabla `EQUIPO` con estadísticas de 20 equipos de fútbol.

## Abrir la página web

**[Ver la presentación en GitHub Pages](https://alfonsodeuna.github.io/BBDD_1DAM/03_CONSULTAS_SIMPLES/)**

## Contenidos

1. **La tabla `EQUIPO`**: estructura, filas, columnas y datos.
2. **`SELECT` y `FROM`**: mostrar toda la tabla o elegir columnas.
3. **`WHERE`**: filtrar por el nombre de un equipo o una condición numérica, y utilizar operadores de comparación.
4. **Práctica individual**: cinco ejercicios y una actividad final para escribir las consultas SQL.

La presentación conserva los ejemplos y botones de respuesta de los apartados 1, 2 y 3. **El apartado 4 no muestra soluciones:** el alumnado debe escribir sus consultas por su cuenta. Esta primera sesión no incluye `ORDER BY` ni `LIMIT`.

## Cómo usarla

- Abrir la página web desde el enlace anterior.
- Navegar con las flechas del teclado o los botones de la presentación.
- Utilizar **«SQL de la tabla»** para descargar el código que crea y rellena la tabla `EQUIPO` en MySQL.
- Escribir las soluciones de los ejercicios en un archivo `.sql` y entregarlo según las indicaciones del profesor.

El material funciona en el navegador sin dependencias externas. La versión web está en [`index.html`](./index.html).
