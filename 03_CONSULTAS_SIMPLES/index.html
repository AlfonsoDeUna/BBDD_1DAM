1. La tabla EQUIPOEjemplo

La estructura de EQUIPO

estructura.sql
CREATE TABLE EQUIPO (
    id_equipo INT PRIMARY KEY,
    nombre VARCHAR(60) NOT NULL,
    goles_favor INT NOT NULL,
    goles_contra INT NOT NULL,
    disparos_puerta INT NOT NULL,
    faltas INT NOT NULL,
    tarjetas_amarillas INT NOT NULL,
    tarjetas_rojas INT NOT NULL
);

id_equipo
Identifica cada equipo.

nombre
Guarda el nombre como texto.

Estadísticas
Guardan cantidades enteras.

El archivo «SQL de la tabla» incluye la creación de la base de datos y los 20 registros.

3. WHEREExplicación

Elegir qué equipos aparecen

WHERE indica la condición que deben cumplir las filas.

consulta.sql
SELECT nombre, goles_favor
FROM EQUIPO
WHERE goles_favor >= 20;

SELECT elige columnas. WHERE filtra filas.

3. WHEREPregunta

El Real Betis tiene 20 goles

condición A
WHERE goles_favor > 20
condición B
WHERE goles_favor >= 20

¿En qué caso aparecerá el Real Betis?

> 20: no aparece. Pide más de 20.

>= 20: sí aparece. Incluye exactamente 20.

3. WHEREActividad

Equipos sin tarjetas rojas

Muestra el nombre y las tarjetas rojas de los equipos que no han recibido ninguna tarjeta roja.

consulta.sql
SELECT nombre, tarjetas_rojas
FROM EQUIPO
WHERE tarjetas_rojas = 0;

Aparecen CA Osasuna, Levante UD y FC Barcelona.

Piensa qué valor numérico representa «ninguna tarjeta roja».
