# Práctica de LaLiga — 1.º DAM

**[Abrir presentación en GitHub Pages](https://alfonsodeuna.github.io/BBDD_1DAM/1_CREACION_TABLAS/PRACTICA_LIGA_FUTBOL/)**

Presentación web interactiva de 9 diapositivas para trabajar las tablas `equipo` y `jugador`.

Se trabaja observación de datos, campos y tipos, cardinalidad 1:N, claves PK/FK, dos `CHECK`, autocorrección del `CREATE TABLE`, generación de `INSERT` con IA y consultas `SELECT`.

El archivo [`index.html`](index.html) funciona de manera autónoma: incorpora estilos, JavaScript y la imagen de cardinalidades.
