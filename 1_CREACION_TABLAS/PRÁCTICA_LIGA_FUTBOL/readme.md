# Práctica: LaLiga y bases de datos (1.º DAM)

**[Abrir la práctica como página web](https://alfonsodeuna.github.io/BBDD_1DAM/1_CREACION_TABLAS/PR%C3%81CTICA_LIGA_FUTBOL/)**

Presentación interactiva de **9 diapositivas** para proyectar o compartir con el alumnado.

## Actividades

1. Observar las estadísticas de LaLiga.
2. Identificar las tablas `equipo` y `jugador` y sus campos.
3. Interpretar el diagrama E-R y la cardinalidad 1:N.
4. Crear las tablas con claves primarias, foránea y dos restricciones `CHECK`.
5. Comparar el código SQL propio con una diapositiva de autocorrección.
6. Utilizar prompts para solicitar los datos a una IA y generar los `INSERT`.
7. Ejecutar dos consultas `SELECT` sencillas y comprobar los datos.

La presentación se encuentra en [`index.html`](index.html) y puede abrirse directamente en GitHub Pages sin instalación ni archivos externos.
