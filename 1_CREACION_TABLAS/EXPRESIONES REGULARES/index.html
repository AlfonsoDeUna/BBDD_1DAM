PASO 1 DE 2

Copia y ejecuta el código inicial

Este código crea la base de datos pulsofit y las tablas socios y clases. Cópialo en tu archivo SQL y ejecútalo una sola vez en una base de datos nueva. Las tablas ya están definidas; los CHECK se añaden en el paso 2.

Código facilitado
CREATE DATABASE pulsofit;
USE pulsofit;

CREATE TABLE socios (
  id_socio    INT AUTO_INCREMENT PRIMARY KEY,
  codigo      CHAR(7)      NOT NULL UNIQUE,
  dni         CHAR(9)      NOT NULL UNIQUE,
  nombre      VARCHAR(50)  NOT NULL,
  apellidos   VARCHAR(80)  NOT NULL,
  email       VARCHAR(100),
  telefono    CHAR(9),
  cp          CHAR(5),
  usuario     VARCHAR(15)  NOT NULL UNIQUE,
  matricula   CHAR(7),
  tipo_cuota  VARCHAR(10)  NOT NULL DEFAULT 'BASICA',
  cuota       DECIMAL(5,2) NOT NULL,
  fecha_alta  DATE         NOT NULL,
  fecha_baja  DATE
);

CREATE TABLE clases (
  id_clase        INT AUTO_INCREMENT PRIMARY KEY,
  nombre          VARCHAR(40) NOT NULL,
  nivel           VARCHAR(10) NOT NULL,
  dia_semana      CHAR(1)     NOT NULL,
  hora_inicio     TIME        NOT NULL,
  hora_fin        TIME        NOT NULL,
  aforo           TINYINT UNSIGNED NOT NULL,
  plazas_ocupadas TINYINT UNSIGNED NOT NULL DEFAULT 0
);

PASO 2 DE 2

Añade las 15 restricciones CHECK

Debajo del código anterior, escribe una sentencia por ejercicio. Cada una añade una regla a una tabla que ya existe. Usa el nombre de restricción indicado y termina cada sentencia con ;.

ALTER TABLE nombre_tabla
  ADD CONSTRAINT nombre_restriccion
  CHECK (condicion);

Es una plantilla: sustituye nombre_tabla, nombre_restriccion y condicion. Ejecuta cada sentencia terminada una sola vez, después del paso 1.

Cómo leer un CHECK
Dentro de los paréntesis escribes la condición que deben cumplir los datos. AND exige que se cumplan ambas condiciones; OR permite que se cumpla al menos una.
Los campos opcionales conservan la posibilidad de valer NULL: un CHECK no los convierte en obligatorios.

Bloque 1. CHECK con expresiones regulares

Utiliza REGEXP_LIKE(columna, 'patron', 'c') dentro del CHECK. El modificador 'c' distingue mayúsculas de minúsculas.

^ inicio del texto

$ final del texto

[0-9] un dígito

[a-z] una letra minúscula

{4} exactamente 4 veces

{4,15} de 4 a 15 veces

[A-Z] una letra mayúscula

(a|b) alternativa a o b

01 · EJEMPLO RESUELTO

El código del socio

En socios, codigo debe contener el prefijo PF- seguido de exactamente cuatro dígitos.

ALTER TABLE socios
  ADD CONSTRAINT chk_socios_codigo
  CHECK (REGEXP_LIKE(codigo, '^PF-[0-9]{4}$', 'c'));

PF- es el texto fijo; [0-9]{4} representa cuatro dígitos. Los símbolos ^ y $ delimitan el formato completo. Con 'c', el prefijo debe escribirse en mayúsculas.

El formato del DNI

El teléfono

Tabla: socios · Nombre: chk_socios_telefono

Cuando tenga valor, telefono debe contener nueve dígitos y empezar por 6, 7, 8 o 9.

04 · AHORA TÚ

El código postal

Tabla: socios · Nombre: chk_socios_cp

Cuando tenga valor, cp debe contener cinco dígitos. Los dos primeros deben formar un número entre 01 y 52; los tres restantes pueden ser cualquier dígito.

05 · AHORA TÚ

El nombre de usuario

Tabla: socios · Nombre: chk_socios_usuario

usuario solo puede contener letras de la a a la z en minúscula, con una longitud entre 4 y 15 caracteres.

06 · AHORA TÚ

La matrícula

Tabla: socios · Nombre: chk_socios_matricula

Cuando tenga valor, matricula debe contener cuatro dígitos seguidos de tres consonantes mayúsculas, sin vocales, Ñ ni Q.

Bloque 2. Otros CHECK

Usa IN para una lista y BETWEEN para un intervalo que incluye sus extremos. Combina condiciones con AND y OR cuando la regla lo requiera.

07 · AHORA TÚ

Los tipos de cuota

Tabla: socios · Nombre: chk_socios_tipo

tipo_cuota solo puede ser 'BASICA', 'PREMIUM' o 'ESTUDIANTE'.

08 · EJEMPLO RESUELTO

La cuota mensual

En socios, la columna cuota debe estar entre 20 y 90 euros, ambos incluidos.

ALTER TABLE socios
  ADD CONSTRAINT chk_socios_cuota
  CHECK (cuota BETWEEN 20 AND 90);

ALTER TABLE socios indica la tabla; ADD CONSTRAINT chk_socios_cuota da nombre a la regla; CHECK (...) establece la condición. Incluye esta sentencia en tu archivo.

09 · AHORA TÚ

La cuota de estudiante

Tabla: socios · Nombre: chk_socios_estudiante

Si tipo_cuota es 'ESTUDIANTE', cuota no puede superar 35 euros.

10 · EJEMPLO RESUELTO

La fecha de baja

En socios, fecha_baja puede ser NULL. Si existe, debe ser igual o posterior a fecha_alta.

ALTER TABLE socios
  ADD CONSTRAINT chk_socios_fechas
  CHECK (
    fecha_baja IS NULL
    OR fecha_baja >= fecha_alta
  );

OR expresa las dos posibilidades permitidas: que no haya fecha de baja o que esa fecha no sea anterior al alta. Para NULL se utiliza IS NULL.

11 · AHORA TÚ

Un nombre sin espacios en los extremos

Tabla: socios · Nombre: chk_socios_nombre

nombre debe tener al menos dos caracteres y no puede empezar ni terminar con un espacio.

12 · AHORA TÚ

Los niveles de las clases

Tabla: clases · Nombre: chk_clases_nivel

nivel solo puede ser 'INICIACION', 'MEDIO' o 'AVANZADO'.

13 · AHORA TÚ

Los días de clase

Tabla: clases · Nombre: chk_clases_dia

dia_semana solo puede ser 'L', 'M', 'X', 'J', 'V' o 'S': de lunes a sábado.

14 · AHORA TÚ

El horario de las clases

Tabla: clases · Nombre: chk_clases_horario

hora_inicio debe ser igual o posterior a '07:00:00', hora_fin igual o anterior a '22:00:00' y el inicio debe ser anterior al fin.

15 · AHORA TÚ

El aforo de las clases

Tabla: clases · Nombre: chk_clases_aforo

aforo debe estar entre 1 y 30, ambos incluidos. Además, plazas_ocupadas no puede superar aforo.

En los ejercicios con IN, la distinción entre mayúsculas y minúsculas depende de la intercalación de la columna. Las reglas de formato que exigen esa distinción utilizan REGEXP_LIKE con 'c'.
