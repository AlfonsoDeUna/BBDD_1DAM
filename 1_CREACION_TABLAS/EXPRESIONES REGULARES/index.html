01 / ACTIVIDAD

Qué tienes que hacer

  1. Crea la base de datos pulsofit y selecciónala con USE.
  2. Escribe el CREATE TABLE socios con las columnas del escenario. Añade los CHECK de los ejercicios 1 a 11 dentro del mismo CREATE TABLE, después de la última columna, o después de crear la tabla mediante ALTER TABLE. Escribe uno por línea, con la forma CONSTRAINT nombre CHECK (condición) y el nombre que indica cada ejercicio.
  3. Haz lo mismo con el CREATE TABLE clases y los ejercicios 12 a 15.
  4. Comprueba cada restricción con un INSERT del dato válido, que debe entrar, y otro del no válido, que debe dar el error 3819 (Check constraint '...' is violated).

Si añades las restricciones dentro del CREATE TABLE, utiliza esta estructura:

SQL · MySQL
CREATE TABLE socios (
  id_socio INT AUTO_INCREMENT PRIMARY KEY,
  -- ... resto de columnas ...
  fecha_baja DATE,
  CONSTRAINT chk_socios_codigo CHECK (...),
  CONSTRAINT chk_socios_dni    CHECK (...),
  -- ... un CHECK por ejercicio ...
);

Añadir restricciones después de crear la tabla

También puedes crear primero las tablas y añadir después cada restricción con ALTER TABLE. Utiliza el nombre de restricción indicado en cada ejercicio.

Sintaxis general (sustituye los nombres y la condición):

SQL · MySQL
ALTER TABLE nombre_tabla
  ADD CONSTRAINT nombre_restriccion CHECK (condicion);

Plantillas para esta actividad (sustituye los puntos suspensivos por la condición):

SQL · MySQL
ALTER TABLE socios
  ADD CONSTRAINT chk_socios_codigo CHECK (...);

ALTER TABLE clases
  ADD CONSTRAINT chk_clases_nivel CHECK (...);

Cada sentencia añade una restricción a una tabla que ya existe. Puedes repetirla para añadir las demás.

Entrega: dos archivos separados

  1. Un archivo .sql con la creación de las tablas, todas las restricciones CHECK y las pruebas con INSERT.
  2. Otro documento con las respuestas a todas las preguntas de reflexión de los bloques 1 y 2.

Las respuestas a las preguntas deben entregarse en un documento aparte del archivo .sql.

02 / ACTIVIDAD

Antes de empezar

MySQL aplica las restricciones CHECK desde la versión 8.0.16; en versiones anteriores las acepta pero las ignora. Todas las soluciones de esta hoja se han probado en MySQL 8.0.

  • REGEXP no distingue mayúsculas. Para que [A-Z] no acepte minúsculas, usa REGEXP_LIKE(columna, 'patrón', 'c').
  • Ancla siempre el patrón con ^ al principio y $ al final; si no, basta con que una parte del texto encaje.
  • Restricciones no permitidas en un CHECK: funciones no deterministas (CURDATE(), NOW(), RAND()), subconsultas, columnas AUTO_INCREMENT y, en un CHECK de columna, referencias a otras columnas.
  • Ponle nombre a cada restricción (CONSTRAINT chk_tabla_campo CHECK (...)): el mensaje de error lo mostrará y podrás borrarla o modificarla después.
03 / ACTIVIDAD

Escenario: Gimnasio PulsoFit

El gimnasio PulsoFit, en Torrejón de Ardoz, quiere que su base de datos rechace los datos mal escritos antes de guardarlos. Partes de estas dos tablas, que todavía no tienen ningún CHECK.

SQL · MySQL
CREATE DATABASE pulsofit;
USE pulsofit;

CREATE TABLE socios (
  id_socio    INT AUTO_INCREMENT PRIMARY KEY,
  codigo      CHAR(7)      NOT NULL UNIQUE,
  dni         CHAR(9)      NOT NULL UNIQUE,
  nombre      VARCHAR(50)  NOT NULL,
  apellidos   VARCHAR(80)  NOT NULL,
  email       VARCHAR(100),
  telefono    CHAR(9),
  cp          CHAR(5),
  usuario     VARCHAR(15)  NOT NULL UNIQUE,
  matricula   CHAR(7),
  tipo_cuota  VARCHAR(10)  NOT NULL DEFAULT 'BASICA',
  cuota       DECIMAL(5,2) NOT NULL,
  fecha_alta  DATE         NOT NULL,
  fecha_baja  DATE
);

CREATE TABLE clases (
  id_clase        INT AUTO_INCREMENT PRIMARY KEY,
  nombre          VARCHAR(40) NOT NULL,
  nivel           VARCHAR(10) NOT NULL,
  dia_semana      CHAR(1)     NOT NULL,
  hora_inicio     TIME        NOT NULL,
  hora_fin        TIME        NOT NULL,
  aforo           TINYINT UNSIGNED NOT NULL,
  plazas_ocupadas TINYINT UNSIGNED NOT NULL DEFAULT 0
);

  • Ejercicio 4 (código postal): separa los dos primeros dígitos del resto. Para la provincia usa tres alternativas entre paréntesis separadas por |: de 01 a 09, de 10 a 49 y de 50 a 52. Detrás van 3 dígitos cualesquiera.
