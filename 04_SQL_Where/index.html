1. La cláusula WHERE1.º DAM · Bases de Datos

¿Para qué sirve WHERE?

WHERE filtra las filas de una tabla: devuelve únicamente los registros que cumplen la condición.

SELECT

¿Qué columnas quiero ver?

FROM

¿De qué tabla?

WHERE

¿Qué filas cumplen la condición?

Sin WHERE, una consulta SELECT no aplica este filtro.

1. La cláusula WHERE1.º DAM · Bases de Datos

Estructura de una consulta con WHERE

Primero elegimos columnas; después decidimos qué registros aparecen

sintaxis.sql
SELECT columna1, columna2
FROM nombre_tabla
WHERE condicion;

1. Elige las columnas que quieres mostrar.

2. Indica la tabla de origen.

3. Escribe la condición del filtro.

Cada operador nos permite establecer una condición diferente

OperadorSignificado¿Incluye el valor indicado?

En MySQL también se acepta != para expresar «distinto de».

2. Operadores de comparación1.º DAM · Bases de Datos

= · Igual a

= Un operador, una condición

consulta.sql
SELECT nombre, goles_favor
FROM EQUIPO
WHERE nombre = 'Getafe CF';
En MySQL Workbench: copia y ejecuta la consulta. Observa las filas que aparecen.
¿Qué buscamos?

Mostrar el nombre y los goles a favor del Getafe CF.

= exige coincidencia exacta con el valor indicado.

En esta consulta comparamos un texto, por eso usamos comillas simples.

2. Operadores de comparación1.º DAM · Bases de Datos

<> · Distinto de

<> Un operador, una condición

consulta.sql
SELECT nombre, tarjetas_rojas
FROM EQUIPO
WHERE tarjetas_rojas <> 0;
En MySQL Workbench: copia y ejecuta la consulta. Observa las filas que aparecen.
¿Qué buscamos?

Mostrar los equipos que tienen alguna tarjeta roja.

<> excluye los registros cuyo valor es cero.

Se mostrarán los equipos con un número de tarjetas rojas distinto de 0.

3. Ejecutar las consultas1.º DAM · Bases de Datos

Textos y números en WHERE

La condición debe respetar el tipo de dato

Comparación con texto
texto.sql
SELECT nombre, goles_favor
FROM EQUIPO
WHERE nombre = 'Celta';

El texto se escribe entre comillas simples.

Comparación con número
numeros.sql
SELECT nombre, goles_favor
FROM EQUIPO
WHERE goles_favor = 20;

Los números se escriben sin comillas.

Las dos consultas se ejecutan en MySQL Workbench, no en esta página.

3. Ejecutar las consultas1.º DAM · Bases de Datos

Prepara MySQL Workbench

Antes de consultar, necesitamos tener cargados los datos

  1. Abre MySQL Workbench y conéctate a tu servidor MySQL.
  2. Comprueba que tienes creada la base de datos liga_select y la tabla EQUIPO de la clase anterior.
  3. Selecciona esa base de datos antes de ejecutar las consultas:
preparacion.sql
USE liga_select;
SELECT * FROM EQUIPO;

Si todavía no tienes la tabla, abre el capítulo 1 y descarga el «SQL de la tabla».

3. Ejecutar las consultas1.º DAM · Bases de Datos

Ejecuta las seis SELECT

Actividad práctica · Usa la tabla EQUIPO

Ahora ejecuta en MySQL Workbench las seis consultas que hemos visto, una por una.

  1. Vuelve a las diapositivas de los operadores.
  2. Usa «Copiar SQL» y pega cada consulta en el editor de Workbench.
  3. Ejecuta la instrucción con el botón del rayo o con Ctrl + Intro.
  4. Observa las filas obtenidas y comprueba que cumplen la condición.
Importante: ejecuta las consultas en MySQL Workbench. Esta web sirve para aprender y copiar el código, pero no consulta la base de datos.

Debes ejecutar las seis consultas de los operadores =, <>, >, <, >= y <=.

Objetivo: interpretar la condición y comprobar el resultado

Después de cada SELECT, revisa lo que muestra MySQL Workbench:

¿Aparecen únicamente los equipos que cumplen la condición?

2

¿Has incluido o excluido el valor límite correctamente?

3

¿Has escrito las comillas cuando comparas textos?

Puedes repetir cada consulta cambiando el valor del filtro para observar cómo cambia el resultado.
