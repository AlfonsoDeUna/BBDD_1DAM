# 04 · SQL WHERE — Operadores de comparación

Presentación web para **1.º DAM · Bases de Datos**. Continuación del capítulo de `SELECT` básicas, utilizando la tabla `EQUIPO` de la base de datos `liga_select`.

## Acceder a la presentación

**[Abrir Capítulo 2 · SQL WHERE en GitHub Pages](https://alfonsodeuna.github.io/BBDD_1DAM/04_SQL_Where/)**

## Contenidos

1. **Cláusula `WHERE`**: qué es, para qué sirve y sintaxis.
2. **Operadores de comparación**: `=`, `<>`, `>`, `<`, `>=` y `<=`, con un ejemplo SQL de cada uno sobre `EQUIPO`.
3. **Textos y números y ejecución en MySQL Workbench**: comillas simples para textos, números sin comillas y una práctica guiada para ejecutar las seis consultas y comprobar sus resultados.

No se incluye el cuestionario, que se realiza por separado en Moodle.

## Cómo utilizarla en clase

- Navega entre las diapositivas con las **flechas izquierda/derecha**, con los botones inferiores o desde **Índice**.
- Puedes proyectarla en **pantalla completa** y utilizar **Copiar SQL** en cada ejemplo.
- Abre **MySQL Workbench**, conecta con tu servidor y selecciona la base de datos con `USE liga_select;`.
- Copia y **ejecuta las SELECT** en Workbench; después comprueba que las filas devueltas cumplen la condición.
- Si falta la tabla `EQUIPO`, puedes obtener el SQL de creación y datos desde el [capítulo 1](https://alfonsodeuna.github.io/BBDD_1DAM/03_CONSULTAS_SIMPLES/).
