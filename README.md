# Bases de datos · 1º DAM

Materiales y actividades para aprender a crear tablas, definir restricciones y trabajar con bases de datos.

## El secreto del doctor Grinberg

Escape room de expresiones regulares: cinco salas y diez pruebas, desde los primeros patrones hasta una restricción `CHECK` con `REGEXP_LIKE` en MySQL. La historia es ficticia.

### Jugar en clase

1. El profesor abre el tablón y crea una partida con el nombre del grupo.
2. Comparte el código o copia el enlace para los alumnos. Puede proyectar el panel a pantalla completa.
3. Cada alumno entra con un alias y el código de la partida. Sin código, el juego funciona como práctica individual.
4. El tablón se actualiza cada cinco segundos: muestra posición, sala, pruebas superadas, tiempo y finalización.
5. El profesor puede cerrar la partida desde el navegador en el que la creó. Para otra clase, crea una partida nueva.

La clasificación prioriza las pruebas superadas; en los empates cuenta quién llegó antes a ese avance. Quienes completan el juego se ordenan por llegada. El tiempo es individual, desde la entrada de cada participante.

El progreso local se conserva en el mismo navegador. Reiniciar una sala permite practicar de nuevo, pero no reduce el avance ya publicado en esa partida. El tablón es una ayuda para la dinámica de clase; el juego comprueba las respuestas en el navegador.
