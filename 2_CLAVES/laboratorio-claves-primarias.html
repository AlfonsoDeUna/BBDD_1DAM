¿Qué es?
La definición

Una clave primaria es un campo o conjunto de campos que identifica de forma única cada registro (fila) de una tabla.

01

Cuatro propiedades que debes conocer

Estas reglas explican cómo funciona una clave primaria.

≠ NULL

No admite NULL

Cada fila debe tener un valor en cada columna de su clave primaria. No puede quedar sin identificar.

≠

Debe ser única

Dos filas no pueden compartir el mismo valor de clave primaria. Si es compuesta, no se repite la combinación.

1 PK

Una por tabla

Una tabla solo puede tener una clave primaria, aunque esta incluya varias columnas.

[a] + [b]

Simple o compuesta

Puede estar formada por una columna o por varias. En este último caso, es una clave primaria compuesta.

◇

Buena práctica: que sea estable. Lo ideal es que su valor no cambie durante la vida del registro.

Es una recomendación de diseño, no una obligación de MySQL.

Así se ve en una tabla

Ejemplo 01 · Clave simple

Alumnos

Un identificador para cada alumno.

alumnos

Los nombres pueden repetirse. id_alumno distingue cada fila, incluso cuando coinciden nombre y apellidos.

Ejemplo 03 · Clave compuesta

Líneas de factura

Dos columnas, una sola clave primaria.

lineas_factura
PK 1/2id_facturaINT
PK 2/2num_lineaINT
productoVARCHAR
id_facturanum_lineaproducto
1011Teclado
1012Ratón
1021Monitor

Se repite la factura y se repite el número de línea. Lo único es el par: (101, 1), (101, 2) y (102, 1).

PK = Primary Key (clave primaria). Datos ficticios para aprender.

Clave primaria ≠ AUTO_INCREMENT

Generar un identificador y definir una clave primaria son dos cosas diferentes.

PRIMARY KEYDefine qué columna o combinación identifica de forma única cada fila.
AUTO_INCREMENTAyuda a generar valores numéricos automáticamente. Por sí solo no convierte una columna en clave primaria.
