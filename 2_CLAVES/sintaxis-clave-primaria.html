Del concepto al código

¿Cómo se escribe PRIMARY KEY?

Al crear una tabla, podemos declarar la clave primaria en la columna o como una restricción de tabla.

La sintaxis general

En la definición de una columna

nombre_columna tipo_dato PRIMARY KEY

Como restricción de tabla

[CONSTRAINT nombre_restriccion]
PRIMARY KEY (columna1 [, columna2, ...])

Los corchetes indican partes opcionales: no se escriben en el código. La forma de tabla permite incluir varias columnas.

Ejemplo 01

En la columna

La clave se declara junto a su tipo de dato.

CREATE TABLE alumnos (
  id_alumno INT PRIMARY KEY,
  nombre VARCHAR(50)
);

id_alumno identifica cada fila. Al insertar un alumno, indicamos su identificador.

Ejemplo 02

Como CONSTRAINT

La clave se declara al final de la tabla.

CREATE TABLE alumnos (
  id_alumno INT,
  nombre VARCHAR(50),
  CONSTRAINT pk_alumnos
    PRIMARY KEY (id_alumno)
);

La clave sigue siendo id_alumno. En MySQL, el nombre efectivo de la clave primaria es siempre PRIMARY, aunque escribamos pk_alumnos.

Ejemplo 03

Con AUTO_INCREMENT

MySQL genera el identificador numérico.

CREATE TABLE alumnos (
  id_alumno INT AUTO_INCREMENT
    PRIMARY KEY,
  nombre VARCHAR(50)
);

AUTO_INCREMENT genera el número si lo omitimos al insertar. PRIMARY KEY lo convierte en la clave primaria.

La misma tabla, tres alternativas. Elige una forma de declarar la clave primaria. No declares dos claves primarias en la misma tabla.

Dos ejercicios para practicar PRIMARY KEY

Observa el esquema y crea la tabla. Puedes escribir aquí o en tu editor MySQL. Los recuadros no ejecutan ni corrigen SQL; abre la solución cuando quieras comparar.

Ejercicio 01 · En columna

Crea la tabla productos

Declara id_producto como clave primaria en la propia columna. En este ejercicio, el identificador se introduce manualmente: no uses AUTO_INCREMENT.

productos
PKid_productoINT
nombreVARCHAR(100)
Ver una posible solución
CREATE TABLE productos (
    id_producto INT PRIMARY KEY,
    nombre VARCHAR(100)
);
Ejercicio 02 · CONSTRAINT + AUTO_INCREMENT

Crea la tabla alumnos

Haz que MySQL genere id_alumno automáticamente. Declara la PK al final de la tabla, usando CONSTRAINT pk_alumnos.

alumnos
PKid_alumnoINT · AUTO_INCREMENT
nombreVARCHAR(100)
Ver una posible solución
CREATE TABLE alumnos (
    id_alumno INT NOT NULL AUTO_INCREMENT,
    nombre VARCHAR(100),
    CONSTRAINT pk_alumnos
        PRIMARY KEY (id_alumno)
);

AUTO_INCREMENT va en la columna; PRIMARY KEY, en la restricción de tabla. En MySQL, el nombre efectivo de la PK es PRIMARY.
