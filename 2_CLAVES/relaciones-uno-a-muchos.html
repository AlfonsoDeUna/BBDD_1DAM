Una relación uno a muchos · 1:N

Un registro de la primera tabla (1) puede estar asociado con varios registros de la segunda (N), pero cada registro de la segunda pertenece a un único registro de la primera.

Ana tiene dos pedidos: el 1001 y el 1002. Ambos guardan id_cliente = 1.

Así se crean las dos tablas en MySQL

-- Tabla principal (Lado 1)
CREATE TABLE clientes (
    id_cliente INT PRIMARY KEY,
    nombre VARCHAR(100)
);
-- Tabla secundaria (Lado N)
CREATE TABLE pedidos (
    id_pedido INT PRIMARY KEY,
    fecha DATE,
    id_cliente INT,
    FOREIGN KEY (id_cliente)
        REFERENCES clientes(id_cliente)
);

La clave foránea se coloca en el lado N. Cada pedido guarda un cliente; el mismo cliente puede aparecer en varios pedidos.

En este código, pedidos.id_cliente admite NULL. Si todo pedido debe tener obligatoriamente un cliente, escribe id_cliente INT NOT NULL.
